# 📅 할 일 달력

간단한 웹 기반 할 일 관리 달력입니다.

## 기능

- 📆 월별 달력 보기
- ✅ 날짜별 할 일 추가/삭제
- ✔️ 완료 표시
- 💾 브라우저 로컬 저장소에 자동 저장
- 📝 할 일이 있는 날짜 표시

## 사용 방법

1. `index.html` 파일을 브라우저에서 열기
2. 달력의 날짜를 클릭
3. 할 일을 입력하고 "추가" 버튼 클릭
4. 완료된 항목은 체크박스로 표시

## 파일 구조

```
memory1/
├── index.html
├── style.css
├── script.js
└── README.md
```
